# SolPath
### Mainnet‑faithful local transaction replay for Solana

SolPath lets you replay any Solana mainnet transaction **exactly** inside a local test environment.  
Catch bugs before they cost you money.

## Current status
✅ RPC transaction fetching – implemented  
🔄 Local fork & replay – in progress (MVP by May 20)  
📖 Documentation – planned
